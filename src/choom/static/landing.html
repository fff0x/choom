Welcome, Choomba.

choom — minimal SSH terminal sharing relay. Share your terminal over SSH, read-only or read-write.

A host shares its local shell through this relay; viewers connect with a plain ssh — no client needed. An optional read-only browser view and asciicast recording round it out. The shell runs on the host; the relay only forwards bytes.

⚠ Public relay — trust the operator. This server trusts a built-in default key, so anyone with the standard client can start a session here. There is no end-to-end encryption: the relay handles your session in cleartext, so its operator can both read everything and inject keystrokes into your shell (the relay forwards input, so it can also originate it) — and may record the session. The read-only / read-write tokens only restrict other viewers, not the operator. Only host on a relay you trust; for anything sensitive run your own private relay (--no-default-key + your own authorized_keys).

Use it

Install the client (Nix or pip), then share your shell:

nix run git+https://seed.this-is-fine.io/zc53mExb6ttoNQXMMZh9xxn5n2HH.git -- host
# or:  pip install choom && choom host

Or grab a standalone binary — see /download/.

The host prints a read-only and a read-write link. Viewers run the ssh command (or open the read-only web link) they were given.
