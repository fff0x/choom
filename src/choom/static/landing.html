Welcome, Choomba.

choom — tmate without tmux. Share your terminal over SSH, read-only or read-write.

A host shares its local shell through this relay; viewers connect with a plain ssh — no client needed. An optional read-only browser view and asciicast recording round it out. The shell runs on the host; the relay only forwards bytes.

⚠ Public relay. This server trusts a built-in default key, so anyone with the standard client can start a session here. The relay sees your session in cleartext (no end-to-end encryption) and may record sessions. Don't share secrets you wouldn't show the operator, and treat a read-write link as handing over a shell. For anything sensitive, run your own private relay (--no-default-key + your own authorized_keys).

Use it

Install the client (Nix or pip), then share your shell:

nix run git+https://seed.this-is-fine.io/zc53mExb6ttoNQXMMZh9xxn5n2HH.git -- host
# or:  pip install choom && choom host

Or grab a standalone binary — see /download/.

The host prints a read-only and a read-write link. Viewers run the ssh command (or open the read-only web link) they were given.
